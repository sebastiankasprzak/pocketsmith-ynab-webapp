Sync Status Fix Test

This test verifies that:

  1. The recent transaction activity time period selection works correctly
  2. The selected time period is remembered using localStorage

Changes Made:

  • Fixed the issue where changing time periods didn't work when auto-refresh was enabled
  • Added localStorage persistence for both activityHours and autoRefresh settings
  • Removed the hardcoded activityHours in useSyncMonitoring hook
  • Updated SyncStatus component to properly pass activityHours to the hook

Technical Details:

The issue was in SyncStatus.tsx where it used useSyncMonitoring() when autoRefresh was true, which had a hardcoded activityHours: 24. Now it uses useSyncStatus() with the proper activityHours parameter in all cases.

localStorage keys used:

  • syncStatus.activityHours - stores the selected time period
  • syncStatus.autoRefresh - stores the auto-refresh toggle state
